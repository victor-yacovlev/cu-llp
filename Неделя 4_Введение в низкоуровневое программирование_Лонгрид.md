## Структуры: объявление, работа со структурами

Структура объединяет несколько значений разных типов в одну именованную сущность. Объявляется структура
ключевым словом `struct`, за которым следует тег структуры и список полей в фигурных скобках:

```c
struct Rectangle {
    double width;
    double height;
};
```

Переменная структурного типа объявляется с обязательным указанием ключевого слова `struct` перед тегом:

```c
struct Rectangle r;
```

К полям структуры обращаются через оператор `.` (точка):

```c
r.width = 3.0;
r.height = 4.0;
```

Как и массивы, переменные структурного типа можно инициализировать при объявлении, в том числе с указанием
конкретных полей по имени:

```c
struct Rectangle r = { .width = 3.0, .height = 4.0 };
```

Рассмотрим задачу: дан массив прямоугольников, для каждого нужно вычислить площадь и периметр, а также
посчитать суммарную площадь всех прямоугольников.

```c
#include <stdio.h>

struct Rectangle {
    double width;
    double height;
};

double rect_area(struct Rectangle r)
{
    return r.width * r.height;
}

double rect_perimeter(struct Rectangle r)
{
    return 2 * (r.width + r.height);
}

int main(void)
{
    struct Rectangle rects[] = {
        { .width = 3.0, .height = 4.0 },
        { .width = 5.0, .height = 2.0 },
        { .width = 1.5, .height = 1.5 },
    };
    size_t n = sizeof(rects) / sizeof(rects[0]);

    double total_area = 0;
    for (size_t i = 0; i < n; ++i) {
        double area = rect_area(rects[i]);
        printf("rectangle %zu: area = %.2f, perimeter = %.2f\n", i, area, rect_perimeter(rects[i]));
        total_area += area;
    }
    printf("total area = %.2f\n", total_area);
    return 0;
}
```

Результат работы программы:

```
rectangle 0: area = 12.00, perimeter = 14.00
rectangle 1: area = 10.00, perimeter = 14.00
rectangle 2: area = 2.25, perimeter = 6.00
total area = 24.25
```

Здесь объявлен массив структур `rects`, каждый элемент которого инициализирован с указанием конкретных
полей. Функции `rect_area` и `rect_perimeter` принимают структуру `struct Rectangle` по значению, то есть
получают собственную копию структуры, переданной при вызове &mdash; в языке C структуры, как и любые другие
типы, кроме массивов, всегда передаются в функции по значению.

### Union: отличие от структуры

Кроме `struct`, в языке C есть родственная конструкция `union` (объединение), которая объявляется и
используется синтаксически почти так же, как структура &mdash; с полями, обращением через `.` и `->`, но
устроена принципиально иначе. Мы уже кратко встречали `union` раньше, в материале про внутреннее
представление чисел, когда с его помощью интерпретировали одну и ту же область памяти то как значение
типа `float`, то как значение типа `uint32_t`, чтобы добраться до знака, экспоненты и мантиссы вещественного
числа. Здесь мы рассмотрим `union` отдельно и подробнее сравним его со структурой.

Главное отличие в том, что у структуры каждое поле имеет собственную, отдельную область памяти, поэтому
размер структуры (с учётом выравнивания) примерно равен сумме размеров всех её полей. У объединения же все
поля делят *одну и ту же* область памяти, поэтому размер объединения равен размеру его самого большого поля
&mdash; и в каждый момент времени в переменной union хранится значение только одного из полей, того самого,
которое было записано последним.

```c
#include <stdio.h>

struct SampleStruct {
    int i;
    double d;
    char c;
};

union SampleUnion {
    int i;
    double d;
    char c;
};

int main(void)
{
    printf("sizeof(struct SampleStruct) = %zu\n", sizeof(struct SampleStruct));
    printf("sizeof(union SampleUnion)   = %zu\n", sizeof(union SampleUnion));

    union SampleUnion u;
    printf("&u.i = %p\n", (void *) &u.i);
    printf("&u.d = %p\n", (void *) &u.d);
    printf("&u.c = %p\n", (void *) &u.c);

    u.i = 42;
    printf("after u.i = 42: u.i = %d\n", u.i);
    u.d = 3.14;
    printf("after u.d = 3.14: u.i = %d (значение испорчено, потому что делит память с u.d)\n", u.i);

    return 0;
}
```

Результат работы программы:

```
sizeof(struct SampleStruct) = 24
sizeof(union SampleUnion)   = 8
&u.i = 0x7ffc36d2ed00
&u.d = 0x7ffc36d2ed00
&u.c = 0x7ffc36d2ed00
after u.i = 42: u.i = 42
after u.d = 3.14: u.i = 1374389535 (значение испорчено, потому что делит память с u.d)
```

Размер `struct SampleStruct` равен 24 байтам &mdash; полям `i` (4 байта), `d` (8 байт) и `c` (1 байт)
отведена отдельная память, плюс добавлено выравнивание. Размер `union SampleUnion`, напротив, равен всего
8 байтам &mdash; размеру самого большого поля, `double`. Адреса всех трёх полей `u.i`, `u.d`, `u.c`
совпадают &mdash; это одна и та же область памяти, интерпретируемая как разные типы. Поэтому, как только мы
записываем в поле `u.d` значение `3.14`, ранее записанное в `u.i` значение `42` оказывается затёрто: поле
`u.i` теперь содержит первые 4 байта битового представления числа `3.14` типа `double`, а вовсе не число 42.

Именно эта возможность интерпретировать одну и ту же память как значения разных типов и использовалась в
примере с разбором `float` на составляющие части: `union { float f; uint32_t u; }` позволяет записать
вещественное число в поле `f`, а прочитать его же битовое представление как обычное целое число из поля
`u`, чтобы применить к нему сдвиги и маски.

## Указатели: объявление, арифметика указателей, массивы и указатели

### Объявление указателей

Указатель &mdash; это переменная, хранящая адрес другой переменной в памяти. Указательный тип объявляется
звёздочкой перед именем переменной:

```c
int x = 10;
int *p = &x;   // p указывает на переменную x
```

Оператор `&` (взятие адреса) даёт адрес переменной, а оператор `*` (разыменование) обращается к значению,
на которое указывает указатель:

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p = &x;

    printf("x = %d\n", x);
    printf("*p = %d\n", *p);

    *p = 20;               // изменяем x через указатель
    printf("x after *p = 20: %d\n", x);
    return 0;
}
```

Каждую переменную указательного типа рекомендуется сразу инициализировать &mdash; либо адресом существующей
переменной, либо нулевым указателем `NULL`, если указатель пока никуда не должен указывать.

### Целочисленная арифметика указателей

К указателю можно прибавлять и вычитать целые числа: `p + i` даёт указатель, смещённый на `i` элементов от
`p` (не на `i` байт &mdash; смещение автоматически умножается на размер типа, на который указывает `p`).
Два указателя, указывающих на элементы одного и того же массива, можно вычитать друг из друга: результат
&mdash; целое число со знаком типа `ptrdiff_t`, равное разности индексов соответствующих элементов.

```c
int values[] = { 1, 2, 3, 4, 5 };
int *p = &values[4];
int *q = &values[0];
printf("p - q = %td\n", p - q);   // 4
```

### Массивы и указатели

Имя массива в выражении почти всегда неявно преобразуется в указатель на его первый элемент. Именно поэтому
для указателей определена операция индексации: `p[i]` означает то же самое, что `*(p + i)`. Благодаря этому
с массивом можно работать через указатель точно так же, как через индексацию по имени массива.

Рассмотрим задачу: развернуть массив на месте (поменять местами первый и последний элементы, второй и
предпоследний, и так далее), используя указательную арифметику.

```c
#include <stdio.h>

void reverse(int *begin, int *end)  // end указывает на элемент сразу после последнего
{
    --end;
    while (begin < end) {
        int tmp = *begin;
        *begin = *end;
        *end = tmp;
        ++begin;
        --end;
    }
}

int main(void)
{
    int values[] = { 1, 2, 3, 4, 5 };
    size_t n = sizeof(values) / sizeof(values[0]);

    reverse(values, values + n);

    for (size_t i = 0; i < n; ++i) {
        printf("%d ", values[i]);
    }
    printf("\n");
    return 0;
}
```

Результат работы программы:

```
5 4 3 2 1 
```

Функция `reverse` принимает два указателя: на начало диапазона и на позицию сразу за его концом &mdash; это
стандартное соглашение для описания диапазона `[begin, end)` в терминах указателей, при котором `end` не
обязательно указывает на существующий элемент, но обязательно является корректным значением указателя (не
далее одного элемента за концом массива). При вызове `reverse(values, values + n)` имя массива `values`
неявно преобразуется в указатель на его первый элемент, а `values + n` &mdash; в указатель сразу за
последним элементом. Внутри функции два указателя, `begin` и `end`, движутся навстречу друг другу, меняя
местами значения, на которые они указывают, пока не встретятся.

Важное отличие массива от указателя: формула `sizeof(arr) / sizeof(arr[0])` для подсчёта количества
элементов работает только для настоящего массива, а не для указателя, даже если указатель хранит адрес
начала массива &mdash; переданный в функцию как параметр массив всегда становится указателем, и внутри
функции у него нельзя узнать исходный размер без передачи размера отдельным параметром. Именно поэтому
функция `reverse` в примере выше принимает границы диапазона явно, а не пытается вычислить размер массива
внутри себя.

## Строки в языке Си, работа со строками

Строка в языке C &mdash; это массив элементов типа `char`, завершающийся нулевым байтом (`'\0'`). У строк
нет отдельно хранимой длины: конец строки определяется по позиции нулевого байта, поэтому любая функция,
работающая со строками, должна либо просматривать байты последовательно до нулевого байта, либо явно
получать длину строки от вызывающего кода.

Реализуем собственную версию функции `strlen`, чтобы увидеть этот принцип на практике, и сравним её
результат со стандартной функцией `strlen` из `<string.h>`:

```c
#include <stdio.h>
#include <string.h>

size_t my_strlen(const char *s)
{
    const char *p = s;
    while (*p) {
        ++p;
    }
    return (size_t) (p - s);
}

int main(void)
{
    const char *s = "Hello, world!";
    printf("my_strlen: %zu\n", my_strlen(s));
    printf("strlen:    %zu\n", strlen(s));
    return 0;
}
```

Результат работы программы:

```
my_strlen: 13
strlen:    13
```

Функция `my_strlen` продвигает указатель `p` по строке байт за байтом, пока не встретит байт со значением 0
(условие `*p` истинно, пока байт по адресу `p` не равен нулю), а затем возвращает разность указателей `p - s`
&mdash; количество байт, пройденных от начала строки до нулевого байта.

Рассмотрим ещё одну задачу: посчитать количество гласных букв латинского алфавита в строке.

```c
#include <stdio.h>
#include <string.h>

int count_vowels(const char *s)
{
    int count = 0;
    for (const char *p = s; *p; ++p) {
        char c = *p;
        if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u'||
            c=='A'||c=='E'||c=='I'||c=='O'||c=='U') {
            count++;
        }
    }
    return count;
}

int main(void)
{
    const char *s = "Hello, world!";
    printf("string:  \"%s\"\n", s);
    printf("length:  %zu\n", strlen(s));
    printf("vowels:  %d\n", count_vowels(s));
    return 0;
}
```

Результат работы программы:

```
string:  "Hello, world!"
length:  13
vowels:  3
```

Здесь `for (const char *p = s; *p; ++p)` &mdash; типичный идиоматический способ обхода строки в языке C:
указатель `p` инициализируется началом строки, условие продолжения цикла &mdash; `*p` (то есть цикл идёт,
пока текущий байт не нулевой), а на каждой итерации указатель продвигается на один байт вперёд оператором
`++p`.

## Выделение, перевыделение и освобождение памяти на куче

В отличие от локальных переменных, память которых автоматически освобождается при выходе из блока, память,
выделенная на *куче* (heap), должна быть явно выделена и явно освобождена программистом с помощью функций
стандартной библиотеки `<stdlib.h>`.

Функция `malloc(size)` выделяет блок памяти размера `size` байт и возвращает указатель на его начало
(`void *`), либо `NULL`, если память выделить не удалось. Функция `realloc(ptr, newsize)` изменяет размер
уже выделенного блока, по возможности сохраняя его содержимое, и тоже возвращает `NULL` при неудаче, не
трогая при этом старое выделение. Функция `free(ptr)` освобождает ранее выделенный блок памяти.

Рассмотрим задачу: собрать в динамически растущий массив квадраты чисел от 0 до 9, не зная заранее точного
количества элементов, которое понадобится хранить.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t capacity = 4;
    size_t size = 0;
    int *arr = malloc(capacity * sizeof(int));
    if (!arr) {
        fprintf(stderr, "%s: out of memory\n", __FUNCTION__);
        return 1;
    }

    for (int i = 0; i < 10; ++i) {
        if (size == capacity) {
            capacity *= 2;
            int *tmp = realloc(arr, capacity * sizeof(int));
            if (!tmp) {
                fprintf(stderr, "%s: out of memory\n", __FUNCTION__);
                free(arr);
                return 1;
            }
            arr = tmp;
            printf("grew capacity to %zu\n", capacity);
        }
        arr[size++] = i * i;
    }

    printf("values: ");
    for (size_t i = 0; i < size; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    printf("size = %zu, capacity = %zu\n", size, capacity);

    free(arr);
    return 0;
}
```

Результат работы программы:

```
grew capacity to 8
grew capacity to 16
values: 0 1 4 9 16 25 36 49 64 81 
size = 10, capacity = 16
```

Программа начинает с блока памяти на 4 элемента. Как только количество уже сохранённых элементов `size`
достигает текущей вместимости `capacity`, вместимость удваивается, и блок памяти перевыделяется функцией
`realloc` под новый, больший размер. Результат `realloc` сначала сохраняется во временную переменную `tmp`
и только после проверки на `NULL` присваивается обратно в `arr` &mdash; если присвоить результат `realloc`
напрямую в `arr` и получить `NULL` из-за нехватки памяти, указатель на исходный, ещё вполне рабочий блок
памяти будет потерян, и освободить его станет невозможно (такая ошибка называется утечкой памяти). В конце
работы с массивом выделенная память обязательно освобождается вызовом `free`.

### calloc: выделение с обнулением и проверкой переполнения

Кроме `malloc`, для выделения памяти под массив есть функция `calloc(n, size)`, которая выделяет блок
памяти для `n` элементов размера `size` байт каждый. От вызова `malloc(n * size)` она отличается двумя
важными вещами.

Во-первых, `calloc` гарантированно обнуляет выделенную память &mdash; каждый байт блока установлен в 0. Это
стандартная гарантия языка C, а не случайность конкретной платформы.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *b = calloc(5, sizeof(int));
    if (!b) {
        fprintf(stderr, "out of memory\n");
        return 1;
    }
    printf("calloc: ");
    for (size_t i = 0; i < 5; ++i) printf("%d ", b[i]);
    printf("\n");
    free(b);
    return 0;
}
```

Результат работы программы:

```
calloc: 0 0 0 0 0 
```

Память, возвращённая `malloc`, в отличие от этого, не инициализирована: её содержимое непредсказуемо, и
полагаться на то, что она случайно окажется нулевой, нельзя &mdash; для гарантированного обнуления следует
использовать именно `calloc` или обнулять память вручную после `malloc`, например функцией `memset`.

Во-вторых, `calloc` сама проверяет умножение `n * size` на переполнение и в случае переполнения возвращает
`NULL`, не пытаясь ничего выделить. При ручном вычислении `n * size` для передачи в `malloc` такой проверки
нет: если результат умножения переполняет `size_t`, он "заворачивается" и превращается в маленькое число,
из-за чего `malloc` выделит блок гораздо меньше, чем на самом деле требуется, — а последующая запись `n`
элементов в этот блок выйдет за его границы.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t n = ((size_t) -1) / 2 + 2;   // подобраны так, что n * size переполняет size_t
    size_t size = 2;

    size_t naive = n * size;   // переполнение size_t: результат "заворачивается", получается маленькое число
    printf("n * size (naive, overflowed) = %zu\n", naive);

    void *p1 = malloc(naive);  // malloc честно выделяет ровно столько, сколько попросили - маленький блок!
    printf("malloc(n * size) = %p\n", p1);

    void *p2 = calloc(n, size);  // calloc сам проверяет n * size на переполнение и отказывает
    printf("calloc(n, size)  = %p\n", p2);

    free(p1);
    free(p2);
    return 0;
}
```

Результат работы программы:

```
n * size (naive, overflowed) = 2
malloc(n * size) = 0x56497a3e02b0
calloc(n, size)  = (nil)
```

Из-за переполнения выражение `n * size` вычислилось как 2 вместо на самом деле требуемых огромных
(и физически невыполнимых) объёмов памяти, поэтому `malloc(naive)` спокойно выделил крошечный блок в 2
байта, хотя по замыслу программы предполагалось выделить блок под `n` элементов. `calloc(n, size)`, получив
те же `n` и `size` по отдельности, сама обнаружила, что их произведение не помещается в `size_t`, и вернула
`NULL`, а не подставной маленький блок. Поэтому при выделении памяти под массив с количеством элементов,
вычисленным во время работы программы (а не заданным константой), обычно безопаснее использовать `calloc`,
чем вручную умножать количество элементов на размер одного элемента и передавать результат в `malloc`.

### strdup, getline и asprintf: функции, сами выделяющие память под строку

В стандартной библиотеке есть несколько функций, которые работают со строками и сами, внутри себя,
выделяют память нужного размера на куче &mdash; вызывающему коду остаётся только не забыть освободить эту
память функцией `free`, когда она больше не нужна.

Функция `strdup(s)` (из `<string.h>`) создаёт копию строки `s`: выделяет блок памяти размера `strlen(s) + 1`
байт и копирует туда содержимое строки вместе с завершающим нулевым байтом. Мы уже использовали её раньше,
в примере с узлом связного списка (`node->str = strdup(s);`), — именно так функция `node_create` получала
собственную, независимую от аргумента копию строки для хранения в узле.

Функция `getline(&lineptr, &n, stream)` (из `<stdio.h>`) читает из потока `stream` одну строку целиком, вместе
с завершающим `\n`, и сама, по мере необходимости, выделяет и перевыделяет буфер `lineptr` нужного размера
&mdash; в отличие от `fgets`, у которого размер принимающего буфера фиксирован заранее и должен быть
известен до чтения. Указатель `lineptr` и его текущая вместимость `n` должны быть либо оба нулевыми
(`NULL` и `0`) перед первым вызовом, чтобы `getline` выделила буфер сама, либо указывать на ранее
выделенный `getline`-ом буфер, который функция при необходимости перевыделит под более длинную строку.
Функция возвращает количество прочитанных байт (без учёта завершающего нулевого байта) либо `-1` при
достижении конца потока или ошибке.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *line = NULL;
    size_t cap = 0;
    ssize_t len;
    int lineno = 1;

    while ((len = getline(&line, &cap, stdin)) != -1) {
        if (len > 0 && line[len - 1] == '\n') {
            line[len - 1] = '\0';
            --len;
        }
        printf("line %d (%zd chars): '%s'\n", lineno++, len, line);
    }

    free(line);
    return 0;
}
```

Если на вход подать две строки, `hello` и `world foo`, программа выведет:

```
line 1 (5 chars): 'hello'
line 2 (9 chars): 'world foo'
```

Буфер `line` и его вместимость `cap` при первом вызове равны `NULL` и `0`, поэтому `getline` сама выделяет
под первую строку блок памяти нужного размера; при чтении второй, более длинной строки функция при
необходимости перевыделяет тот же буфер, увеличивая `cap`. Освобождать буфер `line` нужно только один раз,
после цикла, вызовом `free` &mdash; независимо от того, сколько раз `getline` успела перевыделить его внутри
цикла.

Функция `asprintf(&strp, format, ...)` (объявлена в `<stdio.h>`, доступна как расширение GNU при подключении
`#define _GNU_SOURCE` перед заголовочными файлами) работает как `printf`, но результат форматирования не
выводится на поток, а записывается в новую строку, под которую функция сама выделяет память ровно нужного
размера и записывает указатель на неё в `strp`. Это избавляет от необходимости заранее угадывать размер
буфера, как пришлось бы делать при использовании `sprintf`. Функция возвращает количество записанных байт
либо отрицательное значение при ошибке.

```c
#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *name = "Alice";
    int age = 30;
    char *msg;

    int n = asprintf(&msg, "%s is %d years old", name, age);
    if (n < 0) {
        fprintf(stderr, "out of memory\n");
        return 1;
    }

    printf("msg = \"%s\" (%d bytes)\n", msg, n);
    free(msg);
    return 0;
}
```

Результат работы программы:

```
msg = "Alice is 30 years old" (21 bytes)
```

Строка `msg` выделена функцией `asprintf` в динамической памяти ровно нужного размера &mdash; 22 байта
(21 символ плюс завершающий нулевой байт), и её, как и любую другую динамически выделенную память, нужно
освободить вызовом `free`, когда она больше не нужна.

## Пример работы с односвязным списком строк

Соберём вместе структуры, указатели, строки и динамическую память в одном практическом примере &mdash;
реализации *односвязного списка* (singly linked list) строк. Каждый узел списка хранит одну строку и
указатель на следующий узел; последний узел списка указывает на `NULL`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Node {
    char *str;
    struct Node *next;
};

struct Node *node_create(const char *s)
{
    struct Node *node = malloc(sizeof(struct Node));
    if (!node) {
        fprintf(stderr, "%s: out of memory\n", __FUNCTION__);
        exit(1);
    }
    node->str = strdup(s);
    if (!node->str) {
        fprintf(stderr, "%s: out of memory\n", __FUNCTION__);
        free(node);
        exit(1);
    }
    node->next = NULL;
    return node;
}

void list_push_front(struct Node **head, const char *s)
{
    struct Node *node = node_create(s);
    node->next = *head;
    *head = node;
}

void list_print(const struct Node *head)
{
    for (const struct Node *cur = head; cur; cur = cur->next) {
        printf("%s\n", cur->str);
    }
}

void list_free(struct Node *head)
{
    while (head) {
        struct Node *next = head->next;
        free(head->str);
        free(head);
        head = next;
    }
}

int main(void)
{
    struct Node *head = NULL;

    list_push_front(&head, "C");
    list_push_front(&head, "in");
    list_push_front(&head, "Strings");

    list_print(head);

    list_free(head);
    return 0;
}
```

Результат работы программы:

```
Strings
in
C
```

Разберём программу по частям.

Структура `struct Node` &mdash; это узел списка: поле `str` хранит указатель на строку, размещённую в
динамической памяти, а поле `next` &mdash; указатель на следующий узел списка (или `NULL`, если это
последний узел).

Функция `node_create` выделяет память под новый узел, копирует переданную строку в динамическую память
с помощью функции `strdup` (которая сама выделяет память нужного размера и копирует туда строку) и
инициализирует поле `next` нулевым указателем. Обе операции выделения памяти (`malloc` для самого узла и
`strdup` для строки) проверяются на неудачу; если памяти не хватило, программа выводит сообщение об ошибке
и завершается функцией `exit`.

Функция `list_push_front` добавляет новый узел в *начало* списка: она принимает указатель на переменную
`head`, хранящую голову списка (поэтому параметр имеет тип `struct Node **` &mdash; указатель на указатель,
чтобы функция могла изменить саму переменную `head` в вызывающем коде), создаёт новый узел, связывает его
поле `next` со старой головой списка и делает новый узел новой головой.

Функция `list_print` обходит список от головы до конца, следуя по цепочке указателей `next`, и печатает
строку каждого узла. Условие цикла `cur` истинно, пока `cur` не равен `NULL`, то есть пока не достигнут
конец списка.

Наконец, функция `list_free` освобождает всю память, занятую списком: для каждого узла сначала запоминается
указатель на следующий узел (иначе после освобождения текущего узла мы потеряли бы доступ к остальной части
списка), затем освобождается строка узла, затем сам узел, и обход продолжается со следующего узла.

Строки добавляются в список функцией `list_push_front` в порядке `"C"`, `"in"`, `"Strings"`, но, поскольку
каждая новая строка становится новой головой списка, при печати они выводятся в обратном порядке
добавления: `"Strings"`, `"in"`, `"C"` &mdash; ровно тот порядок, в котором эти же три слова читаются как
осмысленная фраза.
